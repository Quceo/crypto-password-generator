# 🔐 Генератор криптографически стойких паролей

Консольное приложение на Python для генерации надёжных паролей
с использованием криптографически стойкого источника случайности.

## 📌 Зачем этот проект

Стандартный модуль `random` не подходит для генерации паролей: он использует
псевдослучайный алгоритм (Mersenne Twister), который предсказуем при знании
начального состояния. Модуль `secrets` обращается к `os.urandom()` — источнику,
пригодному для криптографических задач.

Проект демонстрирует, как правильно генерировать пароли, не изобретая
собственных «случайных» алгоритмов.

## ✨ Возможности

- Пользователь задаёт длину пароля (минимум 4 символа).
- Гарантированно присутствует **хотя бы один символ каждого класса**:
  цифры, спецсимволы, строчные и заглавные латинские буквы.
- Финальный пароль **перемешивается** через `SystemRandom().sample`,
  чтобы позиции символов разных классов не были предсказуемыми.
- Подтверждение длины перед генерацией.
- Подсказка о надёжной длине (12–16 символов).

## 🧠 Как работает алгоритм

1. Пользователь вводит желаемую длину пароля.
2. Проверяется минимальная длина (4 символа).
3. Пользователь подтверждает выбранную длину.
4. Через `secrets.choice` выбирается по одному символу из каждого класса
   (цифры, спецсимволы, строчные, заглавные).
5. Оставшиеся позиции заполняются случайными символами из общего пула.
6. Пароль перемешивается через `SystemRandom().sample` — это устраняет
   предсказуемый порядок «сначала все классы, потом остальное».
7. Пароль выводится в консоль.

## 🛠️ Стек

- Python 3
- Стандартная библиотека: `secrets` (классы `choice`, `SystemRandom`)
