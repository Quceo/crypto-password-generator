# Crypto Password Generator (Python)

Консольный криптографически безопасный генератор паролей на Python. Проект разработан с фокусом на информационную безопасность: он гарантирует выполнение строгих требований к сложности пароля и полностью защищен от предсказания алгоритмом взлома.

## Ключевые особенности и архитектура проекта

* **Криптографическая стойкость (CSPRNG):** Главным отличием программы от обычных генераторов, использующих стандартный модуль `random` (алгоритм Вихрь Мерсенна), этот проект построен в основном на базе модуля **`secrets`**. Он задействует аппаратные источники энтропии операционной системы, что делает генерируемые пароли математически непредсказуемыми.
* **Гарантированная сложность:** Алгоритм железно обеспечивает наличие **минимум одного** символа из каждой обязательной группы (цифры, специальные знаки, строчные и заглавные буквы) в итоговой строке.
* **Безопасное перемешивание:** Для исключения паттернов (чтобы обязательные символы не шли всегда в начале) применяется метод `SystemRandom().sample()`, который хаотично и надежно перемешивает структуру готового пароля.
* **Рекурсивная логика:** Реализована чистая структура управления в консоли с подтверждением параметров и защитой от некорректных действий пользователя.

## 🛠️ Стек технологий

* **Язык:** Python 3.x
* **Основной модуль:** `secrets` (Cryptographically secure pseudo-random number generator)
